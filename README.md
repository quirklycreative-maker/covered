# Covered

A starter workspace for the Covered project.

## Project structure

- `src/` — application source code
- `tests/` — automated tests
- `docs/` — project documentation
- `assets/` — images and other static assets
- `config/` — configuration files
- `scripts/` — development and maintenance scripts

## Getting started

Choose the language and framework for the project, then add the application code in `src/` and setup instructions here.

## Team collaboration

See [CONTRIBUTING.md](CONTRIBUTING.md) for the branch and pull request workflow. Use GitHub issues to track tasks and bugs, and pull requests to review changes before merging into `main`.
